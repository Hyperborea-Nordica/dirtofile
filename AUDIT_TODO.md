## P0 — Критичные и безопасность

### TODO-001 · Rust · Флаг `-r` не ограничивает рекурсию

- **Статус:** `[x]`
- **Файл / строки:** `rust/src/main.rs` — 121–125, 109–156
- **Суть:** При отсутствии `-r` для подкаталогов выполняется только `continue`, но `WalkDir` продолжает обход. Файлы из вложенных каталогов всё равно попадают в архив.
- **Последствия:** Нарушение заявленного контракта CLI; расхождение с Go-версией; неожиданная утечка данных в архив.
- **Шаги:**
  - [x] Для каталогов `path != base_path` при `!args.recursive` вызывать `entry.skip_current_dir()` (или эквивалент через фильтр глубины).
  - [ ] Добавить unit/integration-тест: дерево `a/b/file.txt`, запуск без `-r` → в архиве только файлы корня.
  - [x] Сверить поведение с Go (`filepath.SkipDir`).
- **Критерий готовности:** Без `-r` в архив попадают только файлы непосредственно в корневой директории `-d`.

### TODO-003 · Go · Ошибки обхода каталога глотаются

- **Статус:** `[x]`
- **Файл / строки:** `go/main.go` — 89–94
- **Суть:** В колбэке `filepath.Walk` при `err != nil` выполняется `return nil` — обход продолжается, ошибка теряется.
- **Последствия:** Неполный архив без сигнала об ошибке; тихая потеря файлов (права, I/O).
- **Шаги:**
  - [x] Strict по умолчанию: ошибка walk → abort (permissive не вводился).
  - [x] Заменить безусловный `return nil` на возврат ошибки.
  - [ ] В `--verbose` печатать предупреждения при permissive (режим не реализован).
  - [ ] Тест: каталог без прав на чтение → ненулевой exit code в strict.
- **Критерий готовности:** Критические ошибки доступа не приводят к «успешному» архиву с пропущенными файлами.
